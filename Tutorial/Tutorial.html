Responsive Webdesign

Dann das Responsive Webdesign, welches sich automatisch an verschiedene Bildschirmgrößen anpasst. Dafür ist das viewport meta Tag notwendig, welches die Breite des Viewports auf die Breite des Geräts setzt. Man braucht es, damit Webseiten auf großen Bildschirmen gut aussehen, ohne Responsive Webdesign müsste man immer Horizontal am Handy scrollen.

Die Media Queries spielen da auch eine große Rolle, damit kann man CSS-Regeln auf unterschiedliche Bildschirmgrößen anpassen.

Z.B body { font-size: 16px; } @media (max-width: 768px) { body { font-size: 14px; } }
